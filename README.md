# ✨ MDS Studio Piercing
Site institucional para estúdio de piercing

O MDS Studio Piercing é um projeto desenvolvido com o objetivo de apresentar o estúdio, seus serviços e sua identidade visual por meio de um site institucional.

🔗 **[Acessar o site]( https://mdsstudiopiercings.lovable.app/)**

## 📖 Sobre o projeto

O projeto surgiu da ideia de criar uma presença digital para o MDS Studio Piercing, reunindo informações sobre o estúdio e seus serviços em um só lugar.

A proposta foi desenvolver uma página que transmitisse a personalidade da marca e facilitasse o acesso dos visitantes às informações e aos canais de contato.

## 💻 Como foi desenvolvido

O desenvolvimento começou com o planejamento da estrutura do site e a definição da proposta visual.

A identidade foi pensada para combinar com o universo do piercing, utilizando elementos modernos e uma composição visual que valorizasse a personalidade do estúdio.

Em seguida, comecei a estruturar as páginas utilizando HTML, organizando as informações sobre o estúdio, os serviços, a galeria e o contato.

Depois, trabalhei na estilização com CSS, ajustando cores, tipografia, imagens e espaçamentos para manter uma navegação organizada e agradável.

## ⚙️ Funcionalidades

- Apresentação do estúdio.
- Seção de serviços.
- Galeria de imagens.
- Informações sobre o atendimento.
- Links para redes sociais.
- Informações de contato.
- Layout responsivo.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
